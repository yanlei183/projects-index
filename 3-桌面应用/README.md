# 💻 桌面应用项目

跨平台桌面应用，主要使用 Qt/QML 技术栈，包括 GUI 工具和系统应用。

## 项目列表

### 1. FileTransfer
**描述**: Qt/QML 文件传输工具  
**特性**:
- 跨平台支持 (Windows、Linux、macOS)
- 图形化界面
- 高效的文件传输
- 美观的 UI 设计

**技术栈**: Qt, QML  
**链接**: https://github.com/yanlei183/FileTransfer

---

### 2. TaoQuick
**描述**: 一套酷炫的 QtQuick/QML 基础库和示例  
**特性**:
- 现代化 QML 组件库
- 丰富的 UI 组件示例
- 高质量代码示例
- 学习 QML 开发的好资源

**内容**:
- 基础库代码
- 完整示例项目
- UI 设计最佳实践

**技术栈**: Qt, QML  
**链接**: https://github.com/yanlei183/TaoQuick

---

### 3. vkgroundcontrol
**描述**: 微克智飞地面站  
**功能**:
- 无人机监控与控制
- 实时数据展示
- 任务规划与执行
- 飞行参数管理

**用途**:
- 无人机地面控制软件
- 专业飞行操作平台
- 数据记录与分析

**技术栈**: Qt, QML  
**链接**: https://github.com/yanlei183/vkgroundcontrol

---

## 技术栈

- **主要框架**: Qt Framework
- **UI 技术**: QML (Qt Modeling Language)
- **支持平台**: Windows、Linux、macOS
- **编程语言**: C++、QML

## 特点

✅ 跨平台兼容性强  
✅ 界面美观、响应迅速  
✅ 代码结构清晰  
✅ 易于扩展和维护

## 学习路径建议

### 初学者
1. 从 **QmlBook-In-Chinese** 开始学习 QML
2. 查看 **blogs** 中相关的入门教程
3. 通过 **mattpocock-skills** 了解工程最佳实践
4. 参考 **diagram-design** 学习系统设计的可视化方式

### 进阶开发者
1. 深入研究 **QmlBook-In-Chinese** 的高级特性
2. 学习 **skills** 中的代理技能开发
3. 参考 **mattpocock-skills** 优化代码结构
4. 掌握 **diagram-design** 进行专业文档设计

### AI 代理开发
1. 学习 **skills** 仓库中的技能定义
2. 参考 **mattpocock-skills** 的工程实践
3. 在 **blogs** 中查找相关教程
4. 使用 **diagram-design** 设计系统架构图表

### 系统设计与文档
1. 学习系统架构图表设计（**diagram-design**）
2. 参考流程文档编写指南（**QmlBook-In-Chinese** 的结构）
3. 查看实际案例（**blogs**）
4. 遵循设计标准（**mattpocock-skills**）

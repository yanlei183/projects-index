# 🚁 无人机/自动驾驶项目

无人机自动驾驶系统、飞控固件、仿真工具等相关项目。

## 项目列表

### 1. ardupilot
**描述**: ArduPilot 开源无人机自动驾驶软件  
**支持平台**:
- ArduPlane (固定翼飞行器)
- ArduCopter (多旋翼无人机)
- ArduRover (地面车)
- ArduSub (水下机器人)

**特性**:
- 完全开源
- 支持多种飞行器类型
- 丰富的传感器集成
- 强大的社区支持

**链接**: https://github.com/yanlei183/ardupilot

---

### 2. Firmware
**描述**: PX4 自动驾驶仪软件  
**特性**:
- 专业级飞控固件
- 支持多种无人机平台
- 先进的飞行算法
- 实时性能

**语言**: C++  
**链接**: https://github.com/yanlei183/Firmware

---

### 3. sitl_gazebo
**描述**: Gazebo 仿真插件  
**用途**:
- SITL (Software In The Loop) 软件在环仿真
- 无人机飞控算法测试
- 虚拟环境中进行飞行测试

**特性**:
- 高保真物理仿真
- 实时渲染
- 支持多种传感器模拟

**语言**: C++  
**链接**: https://github.com/yanlei183/sitl_gazebo

---

## 技术栈

- **主要语言**: C++
- **仿真工具**: Gazebo
- **支持平台**: Linux、Windows、macOS

## 应用场景

- 无人机开发
- 自动驾驶系统
- 飞控固件开发
- 算法验证与测试
- 硬件在环仿真 (HWIL)
- 软件在环仿真 (SITL)

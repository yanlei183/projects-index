# 🤖 AI 智能体项目

基于大语言模型的智能代理系统，包括自动化框架、代理工具包等。

## 项目列表

### 1. agency-agents
**描述**: 一套完整的 AI 代理系统  
**特性**:
- 前端向导代理
- Reddit 社区忍者代理
- 异想天开注入器
- 现实检查器
- 每个代理都有专业化的个性、流程和可验证的成果

**链接**: https://github.com/yanlei183/agency-agents

---

### 2. CLI-Anything
**描述**: 让所有软件成为智能代理原生应用  
**特性**:
- CLI 框架 (CLI-Hub)
- 统一命令行接口
- 支持多种工具集成

**官网**: https://clianything.cc/  
**链接**: https://github.com/yanlei183/CLI-Anything

---

### 3. ego-lite
**描述**: AI 代理浏览器自动化工具  
**特性**:
- 支持共享已登录的浏览器状态
- 无需干扰用户日常操作
- 零成本、零配置
- 为 Codex、Claude Code 等 AI 代理优化

**链接**: https://github.com/yanlei183/ego-lite

---

### 4. pi
**描述**: AI 代理工具包  
**特性**:
- 统一 LLM API 接口
- 代理循环框架
- TUI (文本用户界面)
- 编码代理 CLI

**链接**: https://github.com/yanlei183/pi

---

### 5. gork-build
**描述**: Grok Build 独立发行版  
**特性**:
- 移除了厂商遥测
- 移除了品牌标识
- 基于 Rust 开发
- 社区维护

**语言**: Rust  
**链接**: https://github.com/yanlei183/gork-build

---

- 自动化任务执行

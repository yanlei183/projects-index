# 📱 前端/数据可视化项目

前端框架、数据处理和实时可视化相关项目。

## 项目列表

### 1. cs-data
**描述**: 数据处理库  
**特性**:
- TypeScript 编写
- 强类型数据处理
- 高效的数据结构
- 易于集成

**用途**:
- 数据转换和处理
- 数据管道构建
- 与前端框架集成

**语言**: TypeScript  
**链接**: https://github.com/yanlei183/cs-data

---

### 2. cs-datav
**描述**: 3D 可视地图  
**特性**:
- 三维地图展示
- 实时数据可视化
- 交互式地图控制
- 支持多种数据源

**应用场景**:
- 地理信息系统 (GIS)
- 无人机轨迹展示
- 实时监控系统
- 数据地理化呈现

**链接**: https://github.com/yanlei183/cs-datav

---

### 3. OpenMontage
**描述**: 世界首个开源代理视频生成系统  
**特性**:
- 12条生产管道
- 100+ 生产工具
- 700+ 代理技能和生产知识文件
- 可将 AI 编码助手转变为完整视频生成工作室

**用途**:
- 视频生成自动化
- 内容创作辅助
- 代理视频制作

**链接**: https://github.com/yanlei183/OpenMontage

---

## 技术栈

- **编程语言**: TypeScript、JavaScript
- **可视化库**: Three.js、Cesium.js 等
- **地图框架**: Mapbox、高德地图 API 等
- **视频技术**: FFmpeg、视频处理库

🗺️ 地理信息可视化
